# Roadmaps del proyecto

Los roadmaps documentan la planificacion, ejecucion y cierre de fases del proyecto.

## Estado general

- `actuales/` -- Roadmap vigente o completado recientemente.
- `historicos/` -- Roadmaps de fases ya completadas o superadas. Se conservan como referencia.
- `pagina/` -- Version HTML navegable del roadmap completo.
